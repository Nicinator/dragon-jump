# dragon-jump
A doodle jump inspired jump 'n run game with dragons! This game will include many features that aren't present in doodle jump like for example adjusting the jump height, gliding, breathing fire, an exhaustion mechanic and boss fights.

## Planned features
- Advanced movement system (A -> move left, D -> move right, SPACEBAR -> jump / glide, SHIFT -> drop down, W -> speed boost, S -> rest, E -> breathe fire)
- Exhaustion mechanic (jumping very high repeatedly causes the dragon to lose the ability to glide -> dragon needs to rest for a brief moment)
- Randomly generated islands (some of them break if you stand on top of them for too long)
- Wooden structures that can be destroyed by fire
- After some time, random bosses spawn that need to be avoided while jumping or defeated with fire
